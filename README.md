# MakeMyTrip — Puppeteer QA Automation

## Project Overview

A personal QA automation project focused on testing key MakeMyTrip web application workflows using Puppeteer.

The project demonstrates browser automation, functional validation, regression testing, test design, and AI-assisted QA practices using GitHub Copilot.

## Testing Scope

* Functional Testing
* UI Testing
* End-to-End Testing
* Regression Testing
* Smoke Testing
* Sanity Testing
* Positive Testing
* Negative Testing
* Exploratory Testing
* Compatibility Testing
* Test Automation
* AI-Assisted Testing

## Application Areas

The automation scope includes key travel-booking workflows such as:

* Homepage navigation
* Flight search
* Source selection
* Destination selection
* Travel date selection
* Passenger selection
* Search results
* Flight filtering
* Flight sorting
* Flight details
* Hotel search where applicable
* Navigation and validation

## Automation Framework

**Puppeteer**

The project demonstrates browser automation capabilities including:

* Browser and page automation
* Element interaction
* Navigation
* Selectors
* Assertions
* Screenshots
* Automated workflow validation
* Reusable automation components

## Planned Automation Coverage

The automation suite can cover:

1. Open MakeMyTrip

3. Enter source
4. Enter destination
5. Select travel date
6. Select passenger information
7. Search for flights
8. Validate search results
9. Apply available filters
